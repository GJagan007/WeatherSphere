# 🌦️ WeatherSphere

WeatherSphere is a full-stack weather application built using HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Features

- 🌍 Automatic Geolocation
- 👤 User Name Personalization
- 📍 Latitude & Longitude Collection
- 🌤 Real-time Weather
- 🌡 Temperature & Feels Like
- 💧 Humidity
- 🌅 Sunrise & Sunset
- 📅 7-Day Forecast
- 🕒 Hourly Forecast
- 📊 MongoDB Database
- 🔐 Admin Dashboard

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- wttr.in API

## Run Locally

```bash
npm install
npm start
```

Visit:

```
http://localhost:3000
```
